# HALVETH Morrowind Genesis

**Краткий путеводитель по проекту · EN / RU**

Расширения для существующей лицензионной установки Morrowind, работающей в OpenMW. Исходная документация описывает запуск, графические профили, интерфейсы персонажа и инвентаря, локальное сопровождение диалогов и требования к установке. Данные игры Bethesda берутся из лицензионной установки пользователя.

Genesis Zero — отдельный графический прототип WebGL с движением. HALVETH Realms и HALVETH Portal Garden также являются самостоятельными проектами. Их наличие не доказывает, что исходный мир Morrowind перестроен или что их графические возможности установлены в OpenMW.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
