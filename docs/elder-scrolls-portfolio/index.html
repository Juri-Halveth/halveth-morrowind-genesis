01 / In the existing game

The OpenMW integration

Genesis runs inside a licensed Morrowind installation. The features below are implemented in native OpenMW Lua plus an optional local Python companion, with versioned source and bounded test records.

IDENTITY + TIME

Encounter chronicle

Loaded NPC instances, locations, game days and actual conversations survive save/reload. Regional faction pulses are a separate authored rule.

Inspect the contract →
BOUNDED ACTION

One wanderer

An owned actor uses native wandering, can pause and resume, and is removed only after exact-instance checks. Original quest NPCs retain their own AI.

Read the native receipt →
LOCAL CONVERSATION

Dialogue with context

F8 binds a selected actor, game state and per-instance memory. Generated prose stays separate from original lore and native game actions.

Perspective

Three camera modes and a limited actor projection expose a momentary viewpoint. “Inside the frame” is carefully distinguished from unobstructed sight.

02 / Design idea

A figure can have a history.

OBSERVATIONWhich loaded actor instance was actually encountered, where and when?
CONTINUITYWhich saved events belong to that campaign and instance?
EXPRESSIONWhat may an authored voice say with bounded context?
WORLD AUTHORITYWhich actions may the engine really perform and verify?
“Living” is an engineering question here: persistent identity, movement, response, memory and consequences—each with an observable boundary.
