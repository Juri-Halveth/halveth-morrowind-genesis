# PROTOTYPE_SOURCE_ONLY

This separate MIT source unit is not selected by provision-world.py and has no
installer module name. It remains disabled by default. The generator can build
its own models locally; generated models, debug registrations, native saves,
screenshots and runtime files are excluded from this source-only folder.

SOURCE_BINDING.json retains exact source hashes and the narrow individual
native observations. Those observations apply to the separately generated own
model and frozen0.1.0 source. They do not prove a normal activation UI, all
animation groups, style acceptance or the workshop's combined profile.
