# LEVIATH refinements 0.1.0

Separate optional Crown and Wildlife 0.1.1 units for the exact Workshop 0.2.1
parent. Existing game data, profiles, saves, runtime and Workshop sources stay
external. The package contains owned MIT assets/code and retained CC0 notices;
no new bark images, game assets, previews, private fixtures or controller.

Crown is a model-only override for the existing own tree STAT. Wildlife is an
optional default-OFF owner-control module with one saved own creature. Read
each unit README before preparing a new profile copy. These sources and
receipts belong to one correlated Root/peer/engine provenance cluster.

The collector checks all 215 parent files against the bound 0.2.1 digest, then
the selected exact filenames, source/asset/license hashes and native gates:

Current separate native records bind Crown's broader392-assertion scene and
Wildlife's18+11 observations/21 distinct assertion names through the actual
Player interface, stopped/fresh movement and same-reference reload. These
remain finite observations of the named source/profile/engine, not a general
graphics or physical-key acceptance claim.

```bash
python scripts/package-refinements.py --units crown --parent-root ../leviath-workshop
python scripts/package-refinements.py --units crown,wildlife --parent-root ../leviath-workshop
```

An unpassed selected unit is rejected. The archive option writes a new ZIP
only after these checks. A candidate inspection can inspect a pending unit
without emitting an accepted archive. Hosted CI covers source, declared Lua
models and package boundaries; it does not run the game or replay input.

The Crown builder is LOCAL_PARENT_ONLY. Its checker is
PRIVATE_REBUILD_DEPENDENT, requiring a local scene plan and rebuilding private
outputs. Neither is run by public CI. Public source rebuild portability is a
separate future adapter. Current prebuilt runtime dependencies are bound to
already published parent bytes. See PARENT_BINDINGS.json and unit bindings.

Normal configuration snippets contain only the new mod/data/content lines.
No installer, controller, automatic profile edit or remote activation is
included. Native interface results do not prove physical keyboard delivery,
general style approval, audio acceptance or arbitrary profile compatibility.
